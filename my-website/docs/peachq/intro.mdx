# Getting Started with PeachQ 🍑

[**PeachQ**](https://peachq.org) is an open-source implementation of the Q programming language, bringing the expressive, vector-oriented approach familiar to Q developers into an open and community-driven ecosystem.

For existing Q developers, PeachQ offers a familiar way to experiment with a new implementation. For newcomers, it provides another accessible entry point into the world of Q and vector programming.

In the video below, I'll walk you through **getting started with PeachQ**, from setting up your environment to exploring some of the fundamental concepts that make Q such a powerful and distinctive programming language. We’ll install PeachQ, explore its browser-based REPL, and then dive into four fundamental concepts that will help you understand how Q *thinks*: **atomic operations, vector-oriented programming, right-to-left evaluation, and native data structures including lists, dictionaries and tables**

But enough talking, let's write some Q.
